Fire Docs is a complete guide to programming VEX V5 robots in C++ with PROS. It follows one robot from its first line of code to knowing where it is on the field and following curved paths on its own. Along the way, animations show you how each idea works, and you can pause them, scrub through them, and change their numbers to see what happens.

**Who it's for:** anyone on a VEX team who wants to program. You don't need to have written any code before, because the guide starts at the very beginning. If you already have a robot driving around, skip ahead. The later chapters cover the same control theory and odometry that top teams use, and explain why they work, not only how to copy them.

The chapters build on each other, so read them in order if you're new. Everything is linked, so it also works as a reference when you just need to look something up.
